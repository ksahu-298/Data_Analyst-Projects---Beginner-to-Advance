📌 Project Overview

A PostgreSQL-based exploratory and business analysis project using a Zepto product dataset.

The project covers data exploration, data cleaning, pricing, discounts, inventory, product value, and category-level analysis using practical SQL queries.

Goal: Transform raw product data into insights that can support pricing, inventory, and merchandising decisions.

🧹 Data Cleaning

The SQL workflow includes:

Checking for missing values

Identifying invalid/zero MRP values

Removing invalid MRP records

Converting price values from paise → rupees

Reviewing repeated product names

Validating product and inventory fields

💼 Business Insights

The analysis is designed to help answer practical questions around:

Pricing → Are products competitively priced?

Discounting → Where are the strongest customer offers?

Inventory → Which valuable products are unavailable?

Merchandising → Which categories have stronger pricing/discount patterns?

Product Value → Which products provide better value based on price per gram?

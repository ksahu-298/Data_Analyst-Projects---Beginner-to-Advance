📌 Project Overview

An Excel-based bike sales analysis project that transforms customer-level data into an interactive Bike Sales Dashboard.

The workbook covers data preparation, categorical transformation, Pivot Table analysis, and dashboard creation to explore which customer characteristics are associated with bike purchases.

Goal: Turn raw customer data into clear, decision-oriented sales insights using Microsoft Excel.

🔍 Dataset Variables

The source data contains customer attributes including:

ID · Marital Status · Gender · Income · Children · Education · Occupation · Home Owner · Cars · Commute Distance · Region · Age · Purchased Bike

The working sheet additionally contains an Age Brackets field for demographic analysis.
